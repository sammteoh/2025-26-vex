# VEX Robotics Autonomous Control System

An autonomous control system and driver-interface program developed in C++ using the PROS C/C++ system for VEX V5 hardware.

### Key Highlights
- **Autonomous Routine:** Autonomous movement routines using PID and inertial sensors.
- **Pneumatics:** Control logic for pneumatic pistons, intake mechanisms, and multi-motor drive systems.
- **Color-Based Intake System:** Dynamic intake system using color sensors to determine team or opponent pieces.

### Tech Stack
- **Language:** C++17
- **Framework / Runtime:** PROS (Purdue Robotics OS) for VEX V5
- **Toolchain:** GCC ARM Embedded Toolchain, PROS CLI
